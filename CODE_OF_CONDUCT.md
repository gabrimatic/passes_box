# Code of Conduct

## Summary

This project should be a calm place to work. Keep conversations respectful, practical, and focused on the code or the issue in front of us.

## Expected Behavior

- Be respectful and constructive
- Accept feedback without making it personal
- Focus on what is best for the project

## Unacceptable Behavior

- Harassment, discrimination, or personal attacks
- Publishing others' private information
- Any conduct that does not belong in a professional project

## Enforcement

Project maintainers may remove, edit, or reject contributions that violate this Code of Conduct. Repeated violations may lead to a temporary or permanent ban.
